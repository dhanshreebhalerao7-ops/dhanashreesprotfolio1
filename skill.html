My Skills

Here are some of my technical skills and technologies that I have learned and worked with.

HTML

HTML stands for HyperText Markup Language and is used to create the structure of web pages.

It is used to create headings, paragraphs, images, links, tables, forms and other elements.

HTML works together with CSS and JavaScript to create modern websites.

CSS

CSS stands for Cascading Style Sheets and is used to style web pages.

It controls colors, fonts, layouts, spacing, borders, animations and overall appearance.

CSS helps create responsive and attractive websites for different screen sizes.

JavaScript

JavaScript is a programming language used to make websites interactive and dynamic.

It can handle button clicks, form validation, animations and dynamic content.

JavaScript works with HTML and CSS to create modern interactive web applications.

Python

Python is a high-level, general-purpose programming language with simple syntax.

It is widely used in web development, automation, data science and software development.

Python is also widely used in Artificial Intelligence and Machine Learning.

Django

Django is a high-level Python framework used for building web applications.

It provides features such as authentication, database management and an admin interface.

Django helps developers build secure and scalable web applications efficiently.

MySQL

MySQL is a relational database management system used to store and manage data.

It uses SQL to create, read, update and delete data from databases.

MySQL supports tables, relationships, joins, keys and transactions.

Flutter

Flutter is a framework used to create cross-platform applications.

It uses the Dart programming language and provides a widget-based architecture.

Flutter allows developers to build applications for multiple platforms using one codebase.

React.js

React is a JavaScript library used for building user interfaces.

React applications are created using reusable components.

React supports JSX, props, state and hooks for building dynamic applications.

AI & Machine Learning

Artificial Intelligence enables computers to perform tasks that normally require human intelligence.

Machine Learning allows systems to learn patterns from data and make predictions.

Python libraries such as TensorFlow, PyTorch and Scikit-Learn are commonly used.

Git & GitHub

Git is a version control system used to track changes in source code.

Developers can create branches, commits and restore previous versions of projects.

GitHub provides online hosting and collaboration for Git repositories.
